# TSAI 网关协议

本目录是官方系统协议源码。打包后的 `tsai.yingce-plugin` 可在「插件管理」上传导入，也可随仓库 `plugin-packages/` 在启动时自动安装。本包是声明式协议，不依赖系统宿主 `host:` 执行器。

面向 [TSAI 开发者文档](https://api.alifenqi.com:8188/app/#docs)：一把 Key 覆盖对话、MiniMax H3 / Seedance 2.0 mini 视频，以及 Seedream 4.5 图片。渠道 Base URL 填 `https://api.alifenqi.com:8188`，不要再重复写 `/v1`。

详细接口见 [docs/interface.md](docs/interface.md)。
